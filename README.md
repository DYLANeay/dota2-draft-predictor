# dota2-heroes-selection
Let's help an esport team to choose the best heroes to win on dota 2!

## Repository structure

- `docs/` — project description and working notes
- `code/` — Dota Oracle web app (Flask + LLM agent): setup and usage in `code/README.md`
- `report/` — LaTeX report (arXiv style)
- `data/` — large data files, gitignored
